## 🧠 Modelagem de Ameaças

- As 4 perguntas de Adam Shostack: *O que estamos construindo? O que pode dar errado? O que faremos a respeito? Fizemos um bom trabalho?*
- Abordagens: asset-centric, adversary-centric, software-centric, compliance-centric e risk-centric
- Modelos: SDL, STRIDE, PASTA, VAST e MITRE ATT&CK
- **STRIDE**: Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service e Elevation of Privilege
- Aplicação: inventário de elementos → Diagrama de Fluxo de Dados (DFD) → categorização STRIDE → controles → priorização de riscos
- Priorização com **DREAD**
